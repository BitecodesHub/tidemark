# Code of Conduct

> **Status: Phase 0 draft, 16 October 2026.** The enforcement contact below is a placeholder that the
> founder fills in before the repository is made public.

## Adoption

AgentOS Tidemark (working name) adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, by reference. The full text at that address applies to everyone who takes
part in the project.

In short, participants are expected to be respectful and constructive, and harassment, personal
attacks and the publication of other people's private information are not tolerated.

## Scope

The code of conduct applies in all project spaces: the repository, issues, pull requests,
discussions, security advisories, review threads, project chat channels and project events. It also
applies when someone represents the project in public spaces.

Strong technical criticism is welcome, including criticism of the project's security claims and of
its benchmark. Criticism must address the work, not the person.

## Reporting

Report conduct concerns to: `[ENFORCEMENT CONTACT: to be filled by the founder before the repository
is made public]`.

All reports are reviewed promptly and fairly. The privacy and security of the reporter are
respected.

The project currently has one maintainer, who acts as the community leader under the Covenant. If a
report concerns the maintainer, send it to: `[ALTERNATE CONTACT: an independent person to be named by
the founder, with that person's consent]`. The alternate receives and decides reports that concern
the maintainer (see [GOVERNANCE.md](GOVERNANCE.md)).

## Enforcement

The community leader follows the Enforcement Guidelines in the Contributor Covenant 2.1 (Correction,
Warning, Temporary Ban and Permanent Ban), applied in proportion to the impact of the behaviour.
Enforcement decisions about bans are recorded privately, with a short public note when a ban
affects project spaces.
